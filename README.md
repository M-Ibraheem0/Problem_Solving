# 250 Problems — Structured Problem Solving in Python

A curated run of 250 algorithmic problems solved in Python with a focus on time-constrained thinking, clean reasoning, and pattern recognition across core CS fundamentals.

---

## What This Repository Contains

- **250 Python solutions** organized by category and difficulty
- Each solution written under a self-imposed time limit (no hints, no references mid-solve)
- Inline comments explaining the reasoning, not just the code
- A short retrospective note per problem tracking what slowed the thinking down

---

## Why This Exists

Grinding problems for the sake of a number is easy. This is something different.

Every solution here was written under one constraint: **figure it out in the time you have, with what you know.** The goal is to build the ability to move from an unfamiliar problem to a working, reasoned solution under pressure — the same skill that matters in an interview, a system design discussion, or a production incident.

The problems are not the point. The thinking process is.
